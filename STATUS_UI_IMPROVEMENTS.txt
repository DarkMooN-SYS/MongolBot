                              🎮 NEW COMMANDS ADDED
===============================================================================

👑 **OWNER COMMANDS:**
   ├─ !levelup @user [level_type] [amount] - Manually increase user levels
   ├─ !addxp @user [amount] - Give XP to users (triggers natural level up)
   └─ !resetcooldown @user [type] - Reset user cooldowns (existing)

🏆 **PUBLIC COMMANDS:**
   ├─ !leaderboard [category] - Show top 10 users in various categories
   ├─ !lb [category] - Short alias for leaderboard
   ├─ !top [category] - Alternative alias for leaderboard
   └─ !status [@user] - Enhanced status display (improved)

📋 **LEADERBOARD CATEGORIES:**
   ├─ level - User main levels
   ├─ balance - Wallet money
   ├─ bank - Bank account balance
   ├─ rob_level - Robbery skill levels
   ├─ hack_level - Hacking skill levels
   └─ xp - Experience points
